🎯 Lớp đoán trước?

⚠️ Branch protection + quy ước nhóm: nhánh main yêu cầu ≥ 1 approval. Luật máy: GitHub chặn bạn tự Approve PR của mình, nhưng không mặc định chặn nút Merge. Quy ước nhóm: không ai tự merge PR của chính mình (An merge giúp).
⛔ GitHub báo: "This branch has conflicts that must be resolved" — Bình và Chi cùng sửa một dòng trong config.js.
✅ Xung đột đã được giải quyết thủ công (merge main vào nhánh, sửa markers, commit) và merge thành công vào main.
⛔ GitHub báo: PR bị chặn merge do còn Request changes chưa giải quyết từ An.
✅ Approved: thay đổi đã đáp ứng feedback — PR sẵn sàng để An merge.
💡 Tip (bài giảng): pull/merge origin/main vào nhánh thường xuyên — nhánh nhỏ, ngắn ngày, ít conflict.
🚨 Lỗi nghiêm trọng! Deploy SmartExam sập trang chủ do CSS/JS vừa merge. Ưu tiên cứu main bằng Revert.
✅ Main đã khôi phục! Revert PR gỡ code lỗi. Code cũ vẫn trong lịch sử — Bình tạo nhánh fix để sửa đàng hoàng.
⛔ An phát hiện lỗi: API trả 401 nhưng UI không redirect về /login. Request changes trước khi merge.
✅ Approved: 401 → redirect /login + thông báo "Phiên đăng nhập hết hạn".
💡 Sync: nhánh FE thiếu API mới từ main. Cần git fetch + git merge origin/main.
📝 Draft PR: Chi mở Draft để chốt Mock API contract — Bình code song song. Reviewer không Approve Draft (chủ ý).
📝 Draft PR: chưa Ready — chỉ xin góp ý sớm. Không Approve/Merge Draft.
⚠️ Cảnh báo lab: Branch protection chỉ miễn phí trên repo Public (org Free). Lab bắt buộc repo smartexam Public — hoặc GitHub Education.
💡 Least privilege: Bình/Chi chỉ cần Write; An Maintain (merge); Dũng Admin (CI/protection). Không cấp Admin cho cả nhóm.
💻 Terminal / GitHub 🎯 Dự đoán ON
🎯 Chế độ dự đoán: hỏi lớp trước khi bấm chọn đáp án bên trái. Terminal sẽ hiện sau khi trả lời (hoặc tắt 🎯 để trình chiếu nhanh).
