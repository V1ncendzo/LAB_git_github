⚠️ Branch protection: nhánh main yêu cầu tối thiểu 1 approval — không ai được tự merge PR của chính mình.
⛔ GitHub báo: "This branch has conflicts that must be resolved" — vì Frontend và Backend cùng sửa một dòng cấu hình trong config.js.
✅ Xung đột đã được giải quyết thủ công và merge thành công vào main.
⛔ GitHub báo: PR bị chặn merge do có 1 Request changes chưa được giải quyết từ Reviewer.
✅ Approved: Tất cả các thay đổi yêu cầu đã được đáp ứng và PR sẵn sàng để merge.
💡 Tip: Luôn chạy git fetch + git merge origin/main trước khi tạo PR để tránh conflict và đảm bảo nhánh của bạn có code mới nhất.
🚨 Lỗi nghiêm trọng! Sau khi deploy, phát hiện trang chủ bị sập hoàn toàn do code CSS/JS lỗi vừa merge.
✅ Main đã khôi phục! Revert PR đã gỡ bỏ code lỗi. Dev có thể tạo nhánh mới để sửa đúng cách.
⛔ Reviewer phát hiện lỗi: Khi API trả 401 Unauthorized, UI không tự redirect về trang đăng nhập. Yêu cầu xử lý đúng HTTP status trước khi merge.
✅ Approved: Logic redirect đã hoạt động đúng. Khi API trả 401, người dùng được chuyển về /login kèm thông báo "Phiên đăng nhập hết hạn".
💡 Sync: Nhánh FE đang thiếu code API mới từ main. Cần chạy git fetch + git merge origin/main để tích hợp API thật trước khi tiếp tục code UI.
📝 Draft PR: BE mở Draft PR để chia sẻ schema Mock API sớm cho FE. FE có thể code song song dựa trên contract này mà không cần chờ API thật.
📝 Draft PR: PR này chưa sẵn sàng merge — chỉ để nhận góp ý sớm từ đồng đội. Reviewer không thể Approve một Draft PR.
